# Chess App

A standalone beginner chess learning app for WAMP or shared PHP hosting.

The app teaches basic piece movement with an interactive board and a short quiz. It also includes a beginner move advisor where you can paste a FEN position and get a simple next-move suggestion. Scores are saved locally in the browser.

The move advisor is intentionally simple. It does not analyze uploaded images yet and it is not a full chess engine. For now, use it as a beginner guide and confirm the move is legal in your game.

## Run Locally

Place this folder under WAMP `www`, then open:

`http://localhost/chess-app/`
